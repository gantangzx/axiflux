# 定时提醒技能

## 触发词
- "提醒我xxx"
- "5分钟后提醒我开会"
- "明天上午10点提醒提交报告"

## 执行流程

### 1. 解析提醒内容
从用户输入中提取：
- 提醒时间（绝对时间或相对时间）
- 提醒内容
- 目标会话（发送到当前会话还是指定会话）

### 2. 创建定时任务
调用 scheduler 工具创建 cron 或 delay 任务。

### 3. 确认用户
返回确认信息，包含：
- 提醒时间（人类可读格式）
- 提醒内容
- 任务 ID（用于取消）

## 工具依赖

### scheduler
- 创建 CRON 任务（绝对时间）
- 创建 DELAY 任务（相对时间）

### datetime
- 解析自然语言时间表达
- 转换为 ISO 时间格式

## 示例对话

用户: "提醒我30分钟后喝水"
→ 创建 delay 任务 30 分钟
→ 回复: "好的，已设置 30 分钟后提醒你喝水。任务 ID: task_xxx"

用户: "提醒我明天下午3点开会"
→ 解析为明天下午3点
→ 创建 cron 任务
→ 回复: "已设置明天 15:00 提醒你开会。"
