## 1. 项目背景

产品是一套 **Java 技术栈的响应式 AI Agent 运行时框架 + 企业级 Agent 平台**：

- 内核：自研、全反应式（WebFlux / Reactor）、可作为 Spring Boot Starter 嵌入他人应用；
- 平台：可部署发行版 + 管理控制台，支持多模型、Skill、MCP、知识库 RAG、组织权限、审计与私有化部署；
- 商业形态：**SaaS 订阅 + 自托管 + 离线 License** 三轨。

原中文名"AxiFlux"偏传统、重名多，故启用更具科技感、国际化的新品牌。

## 3. 命名释义

### AxiFlux
- **Axiom（公理）**：第一性原理、不证自明、确定性 —— 对应企业所需的可靠与治理；
- **Flux（流）**：流动、反应式数据流（Reactor `Flux`）—— 对应全反应式内核；
- 组合意：**"公理之流"** —— 让 AI 如公理般确定，如流般运行。

### Reaxon
- **Reactor（反应式）+ React（即时响应）**；
- **Axon（神经元轴突）**：传导神经冲动、触发行动 —— 对应 AI 认知与"感知—行动"；
- 组合意：**反应式地传导思维脉冲，一念即达**。

## 5. Logo 概念

### 5.1 AxiFlux ——「公理之流」
- **核心符号：字母 A × 无限流环（∞ / Flux）**
- 大写 A 骨架象征"公理的起点"；背后/与之叠加一条发光无限循环流线，象征生生不息的反应式数据流；
- 流线中心交叉处为一颗**琥珀金"公理光点"**；负空间可隐约形成一个 `→`（事件/行动）；
- 造型：单线、等宽、圆角端点、几何克制，带轻微流动渐变；
- 寓意：从第一性原理出发，演化为永续流动的智能系统。

### 5.2 Reaxon ——「极简几何 R · 一念脉冲」（已选定）
- **核心符号：统一线宽的几何字母 R × 单一珊瑚脉冲点**
- R 的斜腿自然收束，末端为唯一的珊瑚红发光脉冲点（spark），不做多余分叉；
- 造型克制、圆角、等宽线条，比 AxiFlux 更锐利、有方向与速度感；
- 动态建议：脉冲点沿斜腿向末端传导并点亮（适合启动屏/加载动画）；
- 寓意：反应式地传导思维脉冲，一念触发即行动。

### 5.3 可演进方向（供设计师参考）
- AxiFlux：A 与 ∞ 目前为叠加关系，可探索"一笔连成"的更整体写法；
- Reaxon：可进一步提炼 R 与脉冲点，确保 16px favicon 下仍清晰；
- 需保证：小尺寸清晰、单色/反白可用、图形可独立成图标。

## 6. 视觉规范（简版）

### 6.1 色彩

**AxiFlux（沉稳）**
| 用途 | 色值 |
|---|---|
| 主背景 / 深空藏蓝 | `#0B1020` |
| 主流线 / 电浆青 | `#22D3EE` |
| 流线辅助 | `#38BDF8` → `#818CF8` 渐变 |
| 高光 / 公理光点（琥珀金） | `#F5B94B` |
| 文字 | `#F4F4F5` / `#BCBCC0` / `#8B8B94` |

**Reaxon（带电）**
| 用途 | 色值 |
|---|---|
| 主背景 | `#0B1020` |
| 神经电光青 | `#46E8E3` |
| 信号节点 | `#9CFAF7` |
| 脉冲 / 珊瑚红 | `#FF5C5C`（传承原品牌色） |

### 6.2 字体
- 英文/字标：几何无衬线，建议 **Space Grotesk / Geist / Sora**（AxiFlux 偏几何，Reaxon 偏紧凑，可用 Inter Tight）；
- 代码/技术场景：JetBrains Mono 风格；
- 中文：思源黑体 / 苹方 / 微软雅黑，字重常规—中粗；
- 字标写法：`AxiFlux`（Flux 可加青色渐变）、`Reaxon`（axon 或脉冲点可用珊瑚红）。

### 6.3 图形语言
- 深色底、发光（克制的 glow）、等宽流线、圆角端点；
- AxiFlux 对称/稳态，Reaxon 不对称/带方向；
- 整体保持高级、克制，避免过度霓虹与廉价科幻感。
